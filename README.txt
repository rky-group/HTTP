BEFORE PUBLISHING
1. Keep a backup of your current website.
2. Copy the existing image files into the same folder as these HTML files:
   founder.jpg, Pillar1.PNG, Pillar2.PNG, Pillar3.PNG, Pillar4.PNG, Pillar5.PNG, Pillar6.PNG.
   The existing RKYGROUPLogo.jpg can also be retained, though this design uses a typographic RKY mark.
3. In contact.html, replace REPLACE_WITH_BUSINESS_EMAIL with your real business email address.
4. Review all business descriptions and contact details before publishing.
5. Test all pages locally, especially images and mobile navigation.

GITHUB PAGES
Upload the six HTML files, styles.css, script.js and needed images to the root of your existing repository. Keep the existing branch/folder publishing settings. Commit the changes and wait for the Pages deployment to complete.
